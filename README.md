# Books Catalog

## Архитектура проекта

### Основные сущности

#### Book

Книга содержит:

- название
- год издания
- краткое описание
- ISBN
- изображение обложки

Одна книга может иметь несколько авторов

#### Author

Автор содержит:

- ФИО.

Один автор может быть связан с несколькими книгами

#### BookAuthor

Промежуточная таблица для связи many-to-many между книгами и авторами

#### AuthorSubscription

Подписка гостя на автора

Для подписки нужен только номер телефона. Если для этого автора добавляется новая книга, подписчику отправляется SMS

#### User

Пользователь для входа в систему

Авторизованный пользователь может создавать, редактировать и удалять книги и авторов

## Логика доступа

### Гость

Может:

- смотреть каталог книг
- смотреть авторов
- смотреть отчёт
- подписаться на новые книги конкретного автора

Гость не может:

- создавать книги
- редактировать книги
- удалять книги
- создавать авторов
- редактировать авторов
- удалять авторов

### Авторизованный пользователь

Авторизованный пользователь может:

- смотреть книги
- создавать книги
- редактировать книги
- удалять книги
- смотреть авторов
- создавать авторов
- редактировать авторов
- удалять авторов

## Как развернуть проект

### Клонировать репозиторий

```bash
git clone git@github.com:AL1ATE/books-catalog.git
cd books-catalog
```

### Собрать и запустить контейнеры

```bash
docker compose up -d --build
```

### Установить зависимости

```bash
docker exec -it books_app composer install
```

### Выполнить миграции

```bash
docker exec -it books_app php yii migrate
```

### Создать администратора

```bash
docker exec -it books_app php yii user/create-admin
```

После этого будет доступен пользователь:

```text
Логин: admin
Пароль: admin123
```

## Тест проекта

### Создание автора

1. Войти под admin
2. Открыть раздел `Авторы`
3. Нажать `+ Добавить автора`
4. Заполнить ФИО
5. Сохранить

### Создание книги

1. Войти под admin
2. Открыть раздел `Книги`
3. Нажать `+ Добавить книгу`
4. Заполнить:
   - название
   - год издания
   - ISBN
   - описание
   - авторов
   - обложку
5. Сохранить

### Подписка на автора

1. Выйти из аккаунта
2. Открыть страницу автора
3. Ввести номер телефона
4. Нажать `Подписаться`

Пример телефона:

```text
+79991234567
```

### SMS-уведомление

Когда авторизованный пользователь добавляет новую книгу и выбирает автора, у которого есть подписчики, проект вызывает SMS-сервис

SMS отправляется через отдельный сервис:

```text
services/SmsService.php
```

Логика создания книги и уведомления подписчиков находится отдельно:

```text
services/BookService.php
```

Контроллер не занимается отправкой SMS напрямую

### Проверить подписку

Выйти из аккаунта

Открыть страницу автора и подписаться по номеру телефона

Проверить запись в базе:

```bash
docker exec -it books_mysql mysql -ubooks_user -pbooks_password books_catalog -e "SELECT * FROM author_subscription;"
```

Ожидаемый результат:

- появилась запись с `author_id` и `phone`.

### Проверить SMS

1. Подписаться на автора
2. Войти под admin
3. Создать новую книгу
4. Выбрать этого автора
5. Сохранить книгу

Проверить лог SMS:

```bash
docker exec -it books_app cat runtime/logs/sms.log
```

Ожидаемый результат:

- в логе появилась запись с телефоном, текстом сообщения и ответом smspilot

Пример:

```text
phone=+79991234567 message=Новая книга: Название книги
```
